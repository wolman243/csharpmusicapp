# C Sharp Music Desktop App

A Spotify-inspired desktop application built with **Java** and **MySQL**. This project was developed as a school assignment to demonstrate database management, GUI design, and Object-Oriented Programming.

## 🚀 Features
* **User Authentication:** Secure Login and Sign-up system.
* **Music Library:** Fetch and display song details (Title, Artist, Album) from MySQL.
* **Player Controls:** Basic playback functionality with a custom UI.
* **Playlist Management:** Create and view personalized music lists.
* **Search:** Quickly find tracks within the database.

## 🛠 Tech Stack
* **Language:** Java
* **IDE:** NetBeans (Swing/AWT for UI)
* **Database:** MySQL
* **Driver:** JDBC (Java Database Connectivity)

## 📋 Prerequisites
1. **Java JDK 8 or higher** installed.
2. **MySQL Server** running locally or remotely.
3. **Connector/J** (MySQL JDBC Driver) added to the project libraries.

## ⚙️ Setup
1. Clone the repository.
2. Import the provided `.sql` file into your MySQL Workbench to set up the tables.
3. Update the `DatabaseConnection.java` (or equivalent) file with your MySQL `username` and `password`.
4. Open the project in **NetBeans** and click **Run**.
